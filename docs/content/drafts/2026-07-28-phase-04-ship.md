# I deleted every fake number from my dashboard

For four days, Nucleus's dashboard showed "LangTutor AI · 847 users ·
$210/mo." None of it was real. It was also, honestly, more impressive-looking
than what replaced it.

**Where it stands:** the dashboard now shows exactly what exists -- real
ventures, a real activity feed pulled from the event log, real budget numbers
down to the fourth decimal. Every venture has a real workspace page with a
stage timeline, its full verdict, and per-venture spend.

**The problem:** invented sample data doesn't just look nice, it actively
trains you to stop reading your own product. A dashboard you can't trust is
one you stop checking.

**How it works now:** clicking a venture goes to a real page backed by the
actual file store, no mock in between:

```tsx
export default async function VentureWorkspace({ params }: { params: { id: string } }) {
  const venture = await ventures.get(params.id);
  if (!venture) notFound();
  const [artifacts, spend] = await Promise.all([
    artifactsRepo.listByVenture(venture.id),
    aiCallsRepo.sumByVenture(venture.id),
  ]);
  ...
}
```

**The call I made:** the empty state is a real screen now, not a fallback --
one honest sentence and the New Idea button, nothing invented to fill the
space. A killed venture gets its own muted timeline branch, not a red error
state, because killing a bad idea early is a win the UI should say so about.
