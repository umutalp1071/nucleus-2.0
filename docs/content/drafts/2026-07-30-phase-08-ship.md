# An idea can now become a live URL, inside one AI budget

**Publish date:** 2026-08-15

Yesterday a venture ended at a JSON file. Today it ends at a link you can open in a browser.

**Where it stands:** a venture in the Build stage can generate landing page copy, preview it in an iframe right in the workspace, and publish it -- to a local `file://` URL with zero accounts, or to a real Vercel deployment the moment a `VERCEL_TOKEN` exists. The deployed URL is stored on the venture and a redeploy just overwrites it.

**The problem:** everything Nucleus produces up to this point -- the verdict, the plan, the MVP scope, the build spec -- lives on the founder's own disk. None of it is something a stranger on the internet can see. A venture studio that never publishes anything isn't a studio yet.

**How it works now:**

```ts
export interface DeployTarget {
  deploy(ventureId: string, html: string): Promise<{ url: string; live: boolean }>;
}
// mock: writes .nucleus/deploys/<id>/index.html, zero accounts needed
// vercel: POST /v13/deployments, active the moment VERCEL_TOKEN exists
```

**The call I made:** the publish button stays disabled until the founder checks "I've reviewed the preview above." I rejected auto-enabling it the instant copy generation finished -- a deploy is a one-way door to a public page, and the model's copy has never been read by a human at that point. One checkbox, and nothing goes live unseen.

**Next:** growth -- turning a live page into an actual content calendar.

Total AI cost for idea through a live landing page, on a real OpenRouter key: under $0.20. What's the last thing you shipped where you could say exactly what it cost to make?
