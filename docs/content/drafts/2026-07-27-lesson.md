# A problem I faced today and how I solved it

**Context:** While building Nucleus 2.0's "Save" and "Continue" flows...

**Problem:** The dashboard's page component was a Server Component — no state, no re-renders. But saving an idea needed the Saved Ideas list to update immediately, right there on the same page.

**Solution:** Turned the page itself into a Client Component instead of building a separate wrapper. It was already 100% mock data with zero server-only work happening — the extra file would have bought nothing. `"use client"` at the top, two `useState` hooks, done.

**Lesson:** Before reaching for a new abstraction (a context provider, a wrapper component, a state library), check whether the boundary you actually need is smaller than it looks. Sometimes the fix is one directive on a file you already have open.
