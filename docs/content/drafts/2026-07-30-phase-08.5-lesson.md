# Everything my AI generates is replaceable. Almost nothing it remembers is.

An outside review of the codebase found something I'd missed for eight phases: Nucleus produces judgment and never checks whether the judgment was any good. Not a missing feature -- a missing type.

**What I hit:** the review ran a simple test -- assume a model that's free, instant, and better than any human at every task in the codebase. What survives? Every one of the seven AI tasks collapses into "one prompt." The UI is regenerable in an afternoon. What's left: the budget guard, the willingness to output "kill," and the user's own accumulated outcome history. Everything else was AGI-fodder.

**What I tried first:** the tempting reframe was "move down the stack" -- toward models, toward infrastructure, toward something that feels more defensible. Wrong instinct. Foundation models are the most capital-intensive, fastest-commoditizing layer that exists; price per token drops roughly 10x a year. Moving toward it means competing on capital, the worst fight for one operator on $50/month.

**What worked:** three types -- `Decision`, `Prediction`, `Observation`. A `Plan` was already asking the model for a quantified success metric with a deadline. Nothing ever read that field. It just sat in a card, rendered, forgotten.

```ts
const PredictionSchema = z.object({
  claim: z.string(),
  metric: z.string(),
  target: z.number().nullable(),   // null = qualitative, resolved by judgment
  resolveBy: z.string(),           // the entire point of the type
  status: z.enum(["open", "hit", "missed", "void"]).default("open"),
});
```

Extracting it is a pure function -- the model already did the reasoning, so reformatting it into a tracked claim costs zero AI calls.

**Why this way:** attribution, not measurement, is the hard part. A number on a chart doesn't tell you which decision it's grading. `inputRefs` on `Decision` turns a flat artifact list into a lineage graph, so "the verdict was wrong" has an answer: which upstream reasoning produced it, on what model, at what tier, downgraded or not.

**What it costs:** the eval harness that would actually prove the kill verdict is well-calibrated is still unbuilt -- deliberately deferred until there are real users and real resolved predictions to score against. Building it now would be measuring against nothing.
