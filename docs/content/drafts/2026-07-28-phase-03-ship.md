# I built an AI that tells me to kill my own ideas

**Publish date:** 2026-08-05

Every AI idea-validator I'd tried before was a hype machine. Ask it to
evaluate anything and it hands back "strong potential, 8/10." Nucleus's does
the opposite by default.

**Where it stands:** every idea now gets a real verdict -- a score, a
recommendation, market size, audience pain level, 2-5 named risks, a moat
check, and a `whyNot` field that's required, not optional. Below 40 it kills
the idea outright. Only ideas that clear a bar get a second, more expensive
pass analyzing named competitors.

**The problem:** validators built without a required "argue against this"
field just agree with you. An optional field gets left blank; a required one
forces the model to actually think of the strongest case against.

**How it works now:** every field is asked for by name in the prompt, with
length caps and enums enforced by a schema the model has to satisfy:

```ts
whyNot: z.string(), // required. the strongest argument against building this.
```

And the score, not the model's own self-report, decides the label:

```ts
const band = score < 40 ? "kill" : score < 70 ? "refine" : "build";
```

**The call I made:** competitor analysis -- the expensive, frontier-tier
call -- only runs for ideas that scored 40+. Researching the competition for
an idea the system just told you to kill is exactly the waste a budget guard
exists to prevent.

**Next:** a real venture workspace -- right now this all still happens inside
a modal on top of a dashboard full of fake sample data.
